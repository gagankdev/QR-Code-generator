## 📖 About the Project

The QR Code Generator is a frontend web development project created to make sharing information easier through QR codes.

A QR code (Quick Response code) is a two-dimensional barcode that can store information such as website URLs, text, and other supported data. When scanned using a smartphone camera or QR scanner, the encoded information can be read quickly.

With this application, users can enter a website link or supported text and generate a QR code that represents that information.

For example, enter `https://www.google.com`, generate the QR code, and scan it with a smartphone. The scanner recognises the Google URL, allowing the user to open the website.
